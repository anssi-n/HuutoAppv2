How it works

The import happens in two steps:
1. Images are uploaded first – image files must exist on the server before the CSV can reference them.
2. The CSV file is imported and each row becomes an item that gets queued for publishing.

The CSV is pipe-delimited (|) with a header row and exactly 16 columns. The last column of each data row is a keyword flag (0 or 1). The images column references already-uploaded files with a type:filename pair, separated by semicolons.

Images are limited to 10 MB each, and are uploaded one at a time with visible progress – the browser waits as long as it takes and never times out.

Files are stored by their original name, so the CSV images column can reference them (e.g. fullsize:front.jpg).
