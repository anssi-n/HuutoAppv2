How it works

The import happens in two steps:
1. Images are uploaded first – image files must exist on the server before the CSV can reference them.
2. The CSV file is imported and each row becomes an item that gets queued for publishing.

The CSV is pipe-delimited (|) with a single header row listing the 17 columns in order:

title | images | price | quantity | offers_allowed | description | media_format | genre | country | region | subtitles | packaging | slipcover | condition | shipping | discount_info | add_keywords

title (max 60 chars) and description are free text; price is a float; quantity is an integer 1–5; offers_allowed, slipcover and add_keywords are 0/1; the label columns use the same values as in Add Item; discount_info is fixed to 0. The images column contains preview:<name> for the first image and fullsize:<name> for the rest, separated by ;.

Images are limited to 10 MB each, and are uploaded one at a time with visible progress – the browser waits as long as it takes and never times out.

Files are stored by their original name, so the CSV images column can reference them: the first selected image becomes preview:<name>, the rest fullsize:<name>.

    Build a CSV right here. Each row you add becomes one item. The first image selected on a row becomes the preview, the rest fullsize. When you press Generate CSV, the created file is set as the selected CSV and all used images as the selected images – then press Import.
